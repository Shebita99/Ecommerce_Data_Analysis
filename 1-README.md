# E-Commerce Data Analysis Project

## Project Overview

This is my first end-to-end Data Analysis project, fully created by me from A to Z.

The project focuses on analyzing an E-Commerce dataset to understand overall business performance, customer behavior, marketing performance, product performance, inventory trends, and revenue forecasting.

The project was developed using Microsoft Excel and Power Query, covering the complete data analysis process from data preparation and transformation to KPI development, analysis, visualization, and dashboard creation.

## 📊 Key Performance Indicators

- Total Revenue: $10,827,118.91

## 📈 Dashboard Sections

### 1. Overview

The Overview Dashboard provides a high-level view of the business performance, including:

- Total Orders
- Total Revenue
- Average Order Value (AOV)
- Revenue Trend by Year
- Revenue by Brand
- Revenue by Product Category

### 2. Customer & Marketing Analysis

This dashboard focuses on customer behavior and marketing performance.

The analysis includes:

- Total Sessions
- Customer Purchases
- Add-to-Cart Activity
- Revenue by Gender
- Revenue by State
- Customer Traffic Sources

### 3.Forecasting & Revenue Analysis

This section focuses on revenue trends and future performance.

The analysis includes:

- Historical Revenue Trends
- Revenue Forecast
- Forecast Confidence Intervals
- Revenue vs. Cost Analysis
